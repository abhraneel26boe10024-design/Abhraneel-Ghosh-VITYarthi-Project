# Abhraneel-Ghosh-VITYarthi-Project
Health Campaign System
🏥 Healthcare Awareness Campaign Management System

A beginner-friendly Python-based Healthcare Awareness Campaign Management System developed as part of the VITyarthi Python Essentials Project.

The project allows students to view different healthcare awareness campaigns and register their participation by providing basic student details.

---

📌 Project Overview

Healthcare awareness plays an important role in educating students about healthy lifestyles, nutrition, mental well-being, blood donation, and prevention of harmful substances.

This project provides a simple console-based system where students can:

- View available healthcare awareness campaigns
- Register for a campaign
- Enter student details
- Store registered student information
- Display campaign information
- Provide basic health-awareness information
