Health Awareness Campaign Registration System

This project is a simple Python-based Health Awareness Campaign Registration System developed for the VITyarthi Python Essentials course. It allows students to view different health-awareness campaigns and register their details for participation.

The project demonstrates basic Python concepts such as lists, dictionaries, functions, loops, conditional statements, and user input.

Campaigns Included

- Health Awareness
- Nutrition Awareness
- Mental Health Awareness
- Blood Donation
- Drug Abuse Prevention

Technology

Python 3

Purpose

To apply Python programming concepts to a practical real-world problem while promoting awareness about important health-related topics.
